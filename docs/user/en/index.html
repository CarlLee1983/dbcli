dbcli Documentation

dbcli is a high-performance, security-first Database CLI specifically designed for both human developers and AI agents. It provides a unified interface for SQL, NoSQL, Key-Value, and Search databases.

🛡️ Core Philosophy & Security

Built with a "Security-First" mindset, dbcli prevents accidental data leaks or corruption through multiple layers of protection:

Permission Guard Four tiers (query-only to admin) of strict access control.
Blacklist Manager Automatic redaction of sensitive columns and tables from all outputs.
Plan Mode Static SQL analysis to identify risks before connecting to any DB.
Antigravity Protocol Strict Architect-Builder-Auditor workflow for reliability.

🚀 Getting Started

Install globally using your preferred package manager:

# Using npm
npm install -g @gravito/dbcli

# Using Bun (Recommended)
bun install -g @gravito/dbcli

Initialize your first connection with the interactive wizard:

dbcli init

🔌 Connection Management

Switch between Production, Staging, and Local environments with ease:

dbcli use --list         # List all connection names
dbcli use staging        # Switch your default connection
dbcli query --use prod "SELECT count(*) FROM users" # Temporary override

Querying & Data Operations

# Raw Query
dbcli query "SELECT * FROM users LIMIT 10"

# Run Snippet
dbcli q @snippet --param id=1

# Export Data
dbcli export "SELECT * FROM logs" --format csv --output logs.csv

# Safe Write
dbcli insert users --data '{"name":"Alice"}' --dry-run

Snippet Management

Maintain complex queries as version-controlled snippets in your repository.

  • dbcli queries list: View the full inventory of snippets.
  • dbcli queries search: Search snippets using fuzzy keywords.
  • dbcli queries suggest: Get suggestions based on operational intent.

Health & Diagnostics

📊 Interactive HTML Dashboards

Generate standalone React-powered reports by appending the --ui flag.

dbcli query "SELECT day, count(*) FROM sessions" --ui

Rich visualizations (charts, KPIs) can be configured via the visual: block in snippet frontmatter.
