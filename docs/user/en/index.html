dbcli Documentation

dbcli is a high-performance, security-first Database CLI specifically designed for both human developers and AI agents. It provides a unified interface for SQL, NoSQL, Key-Value, and Search databases.

🛡️ Core Philosophy & Security

Built with a "Security-First" mindset, dbcli prevents accidental data leaks or corruption through multiple layers of protection:

  • Permission Guard: Four tiers (query-only to admin).
  • Blacklist Manager: Automatic redaction of sensitive columns.
  • Plan Mode: Static SQL analysis before execution.
  • Antigravity Protocol: Architect-Builder-Auditor workflow.

🚀 Getting Started

Install globally via npm or bun:

npm install -g @gravito/dbcli
# or
bun install -g @gravito/dbcli

Initialize your first connection:

dbcli init

🔌 Connection Management

Manage multiple environments (Production, Staging, Local) easily:

dbcli use --list         # List connections
dbcli use staging        # Switch default
dbcli query --use prod "..." # One-shot override

Querying & Data Operations

dbcli query "SELECT * FROM users LIMIT 10"
dbcli q @snippet --param id=1
dbcli export "SELECT * FROM logs" --format csv --output logs.csv
dbcli insert users --data '{"name":"Alice"}' --dry-run
dbcli plan "DELETE FROM users" # Analyzes risk

Snippet Management

Reusable SQL snippets with parameters and visualization metadata.

  • dbcli queries list: See all available snippets.
  • dbcli queries search: Fuzzy keyword search.
  • dbcli queries suggest: Context-aware suggestions.

Advanced Tools

  • Shell: dbcli shell - Interactive REPL with Tab-completion.
  • Migrate: dbcli migrate create/drop/alter - DDL engine.
  • Skills: dbcli skill --install - AI instructions.

📊 Interactive HTML Dashboards

Pass the --ui flag to any query to generate and open a rich React-based interactive report.

dbcli query "SELECT day, count(*) FROM sessions" --ui

Visualizations are defined in the snippet frontmatter via the visual: block.
