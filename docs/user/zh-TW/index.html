dbcli 完整說明文件

dbcli 是一款專為人類開發者與 AI 代理設計的高效能、安全優先的資料庫 CLI 工具。它為 SQL、NoSQL、Key-Value 及 Search 資料庫提供統一的操作介面。

🛡️ 核心理念與安全性

dbcli 以「安全第一」為核心，透過多層保護機制防止資料意外洩漏或損壞：

  • 權限守衛 (Permission Guard)：四層存取控制（從 query-only 到 admin）。
  • 黑名單管理器 (Blacklist Manager)：自動屏蔽敏感欄位。
  • 計畫模式 (Plan Mode)：執行前的靜態分析。
  • Antigravity 協議：架構師-建設者-稽核員的工作流。

🚀 快速入門

透過 npm 或 bun 進行全域安裝：

npm install -g @gravito/dbcli
# 或
bun install -g @gravito/dbcli

初始化您的第一個連線：

dbcli init

🔌 連線管理

輕鬆管理多個環境（正式、測試、開發）：

dbcli use --list         # 列出所有連線
dbcli use staging        # 切換預設連線
dbcli query --use prod "..." # 單次覆蓋執行

🛠️ 指令詳解

探索與發現

指令用途
list列出資料表、集合、鍵或索引。
schema顯示結構並快取元資料。
inspect為 AI 提供上下文快照。
status配置健康度摘要。

查詢與資料操作

dbcli query "SELECT * FROM users LIMIT 10"
dbcli q @snippet --param id=1
dbcli export "SELECT * FROM logs" --format csv --output logs.csv
dbcli insert users --data '{"name":"Alice"}' --dry-run
dbcli plan "DELETE FROM users" # 風險分析

儲存查詢管理

具備參數化與視覺化元資料的可重複使用 SQL 片段。

  • dbcli queries list：檢視所有可用片段。
  • dbcli queries search：模糊關鍵字搜尋。
  • dbcli queries suggest：意圖導向建議。

健康度與診斷

指令用途
doctor環境與連線健康檢查。
report完整的健康、容量與效能報告。
guide針對特定目標（如慢查詢）的引導。
recover常見錯誤的自動化修復。

進階工具

  • Shell：dbcli shell - 互動式 REPL。
  • Migrate：dbcli migrate - DDL 結構變更引擎。
  • Skills：dbcli skill --install - AI 專用指引。

📊 互動式 HTML 儀表板

在查詢時加上 --ui 旗標，即可產生並開啟豐富的 React 互動式報表。

dbcli query "SELECT day, count(*) FROM sessions" --ui

視覺化設定定義在 Snippet 的 visual: 區塊中。

🤖 AI 代理整合

Dbcli 從設計之初就是「代理導向」的：

  • --recovery：機器可讀的失敗封包。
  • --for-agent：精簡的 JSON 輸出以節省 Token。
  • Task Packs：預定義的專家工作流。
