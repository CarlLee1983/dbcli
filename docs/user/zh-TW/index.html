dbcli 完整說明文件

dbcli 是一款專為人類開發者與 AI 代理設計的高效能、安全優先的資料庫 CLI 工具。它為 SQL、NoSQL、Key-Value 及 Search 資料庫提供統一的操作介面。

核心理念與安全性

dbcli 以「安全第一」為核心，透過多層保護機制防止資料意外洩漏或損壞：

權限守衛 (Permission Guard) 四層存取控制（從 query-only 到 admin），嚴格把關。
黑名單管理器 (Blacklist Manager) 從所有查詢結果中自動屏蔽敏感資料表與欄位。
計畫模式 (Plan Mode) 在不連線資料庫的情況下進行靜態 SQL 風險分析。
Antigravity 協議 嚴謹的架構師-建設者-稽核員工作流，確保高可靠度。

快速入門

使用您偏好的套件管理器進行全域安裝：

# 使用 npm
npm install -g @gravito/dbcli

# 使用 Bun (推薦)
bun install -g @gravito/dbcli

透過互動式導覽初始化您的第一個連線：

dbcli init

連線管理

輕鬆在正式 (Prod)、測試 (Staging) 及本地 (Local) 環境間切換：

dbcli use --list         # 列出所有連線名稱
dbcli use staging        # 切換預設連線
dbcli query --use prod "SELECT count(*) FROM users" # 單次覆蓋執行

指令詳解

探索與發現

指令用途
list列出資料表、集合、鍵或索引。
schema顯示結構並重新整理本地元資料快取。
inspect上下文快照（物件、權限、建議行動）。
status配置與連線健康度摘要。

查詢與資料操作

# 原生查詢
dbcli query "SELECT * FROM users LIMIT 10"

# 執行 Snippet
dbcli q @snippet --param id=1

# 匯出資料
dbcli export "SELECT * FROM logs" --format csv --output logs.csv

# 安全寫入
dbcli insert users --data '{"name":"Alice"}' --dry-run

儲存查詢管理

在版本控制中維護複雜的查詢片段，支援參數化與視覺化元資料。

  • dbcli queries list：檢視所有可用片段。
  • dbcli queries search：使用模糊關鍵字搜尋。
  • dbcli queries suggest：根據操作意圖獲取建議。

健康度與診斷

doctor 驗證執行環境、連線能力及配置完整性。
report 產生涵蓋健康度、效能及容量的全面報告。
recover 針對常見失敗模式執行自動化修復計畫。

📊 互動式 HTML 儀表板

在指令後加上 --ui 旗標，即可產生獨立的 React 報表並自動開啟。

dbcli query "SELECT day, count(*) FROM sessions" --ui

豐富的視覺化組件（圖表、KPI）可透過 Snippet frontmatter 中的 visual: 區塊進行設定。

🤖 AI 代理整合

Dbcli 是專為現代 AI 代理設計的標準「資料庫驅動程式」：

  • 機器可讀錯誤：JSON 格式的 --recovery 故障修復封包。
  • 內容優化：--for-agent 旗標大幅減少 Token 消耗。
  • 專家任務包：針對診斷與稽核的引導式工作流。
